# Decks en cours de codage

Un deck dont toutes les cartes ne sont pas encore codées attend ici
(`NN_nom.txt`). Aucun programme ni test ne lit ce dossier : `main` reste au
vert pendant le codage. Quand `cargo run -p fab-cards --bin verifier-deck --
data/decks/en_cours/NN_nom.txt` répond « deck complet », le fichier passe
dans `data/decks/`. Procédure complète : `docs/nouveau-deck.md`.
